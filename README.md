# CRNA/SRNA Interactive Study Guide

A high-intensity, browser-based study platform for nurse anesthesia students, built with plain HTML/CSS/JavaScript for easy offline use.

## What this includes

- A **performance dashboard** for tracking quiz volume, accuracy, mastery, and streak.
- A **core domain library** spanning physiology, pharmacology, airway, special populations, crisis management, and safety.
- **Rapid recall flashcards** for high-yield exam concepts.
- An **adaptive quiz engine** that increases focus on weaker topics over time.
- A **critical event protocol trainer** for key anesthesia emergencies.
- A **public-reference orientation** grounded in widely available practice standards and educational materials.

## Run locally

Because this is a static web app, simply open `index.html` directly in your browser.

Or run a lightweight local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Educational note

This project is for study support and deliberate practice. Always defer to your CRNA program curriculum, faculty teaching, and institutional policies.
